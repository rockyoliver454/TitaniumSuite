# Changelog — Titanium Suite

## 2.3 — public release

- First public drop of the suite: four KISS Ada tools composing a
  complete X11 desktop — **TitaniumLogin** (console DM, PAM),
  **TitaniumWM** (tiling window manager: workspaces, Xinerama
  per-screen worlds, floating/monocle/tiling, session persistence,
  ICCCM soft-close), **TitaniumRun** (Alt+D launcher), and
  **TitaniumBG** (animated procedural root wallpaper rendered by a
  SPARK-mode software vGPU: plasma, snowy village, jungle river,
  desert mountain scenes, fractals, procedural flora, dithering).
- Ships `launch_protocol.sh` Xephyr test harness with the
  `launch_auth.dat` checksum gate.
